# Meta Ads 创意生成契约

使用本参考文档规划 Facebook 和 Instagram 创意。版位比例、安全区域、时长、文案截断、文件限制、增强行为和格式可用性都是易变内容。渲染前，依据当前官方证据和所选 Ads Manager 账户确定这些内容。

## 规格关卡

为精确的广告系列目标和广告资源构建版位矩阵。对于每个 Feed、Stories、Reels、轮播、视频、消息或其他所选版位，记录官方来源 ID 和日期、比例、尺寸、文件类型及大小、时长、文案字段、安全区域、裁切/叠加行为和资格。

无法验证当前规格或账户广告载体时，返回 `needs_input`。不要将某版位的可见文案或安全区域规则应用于另一版位，也不要声称某种比例普遍表现最佳。

## Meta 专属审查

- 确认自动版位、创意增强、商品目录素材、音乐、文字变体和图像扩展是否已启用且符合资格。
- 预览所有计划使用的 Facebook 和 Instagram 版位。UI 叠加层和裁切因广告载体、设备和产品版本而异。
- 在所有已批准预览中，保持核心承诺、产品、品牌标识和所需披露清晰，不依赖缺乏依据的硬编码像素区域。
- 对于轮播，保留叙事和视觉连贯性，同时将每张卡片记录为独立素材，带有自己的目标页面和文案。
- 保持创意概念实质不同；对同一图像调整尺寸是覆盖补全，而非创意多样性测试。

## 输出契约

素材清单记录概念 ID、版位、规格来源 ID、比例、尺寸、格式、相关时的时长、文案字段、校验和、溯源、权利、安全审查、预览结果和自动化设置。生成素材是草稿。本技能不意味着具备实时 Meta 上传或变更能力。
