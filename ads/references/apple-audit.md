# Apple Ads 控制项参考

检索日期：2026-07-11。在本参考文档的控制平面刷新日期之后使用前，请刷新官方产品、API、政策和可用性来源。

## 类别模型

本参考文档不定义可执行的评分配置。绑定一个带版本的配置，其类别须涵盖适用控制项，且权重总计为 100；否则，只生成发现，不提供健康分数。确定性引擎仅在对各类别内的适用控制项评分后应用权重。

## 运行时评估契约

- 将每一行视为优先检查适用性的证据问题。缺失证据为 `unknown`；不可用或不符合资格的广告载体为 `not_applicable`。
- 评估前核实应用、市场、版位、广告系列类型、报告访问权限、归因路径和账户资格。
- 下列已登记来源仅为开发者 API 范围提供依据。当前产品、政策、归因、隐私阈值、报告字段、出价和创意声明需要额外的注明日期的官方来源 ID 或账户证据。
- 本参考文档仅用于咨询和读取导出数据。它不提供实时 Apple Ads API 读取器或变更适配器。

## 控制项

| ID | 类别 | 证据问题 |
| --- | --- | --- |
| AP-M01 | 衡量 | 已声明 AdServices、AdAttributionKit、MMP 或内部归因来源及限制。 |
| AP-M02 | 衡量 | 安装和安装后事件已在 Apple Ads 与应用分析来源之间核对一致。 |
| AP-M03 | 衡量 | 归因隐私阈值和缺失细节被视为不确定性，而非零表现。 |
| AP-M04 | 衡量 | 广告系列、版位、广告组、关键词、搜索词和广告报告采用可比窗口。 |
| AP-S01 | 结构 | 在具有实质影响时，广告系列区分品牌、类别、竞品、发现和版位意图。 |
| AP-S02 | 结构 | Search Match 发现和手动定向关键词没有造成失控的重叠。 |
| AP-K01 | 关键词 | 匹配类型、否定关键词、搜索词和关键词迁移遵循已观察到的查询证据。 |
| AP-K02 | 关键词 | 出价和 CPT 决策同时考虑点按率、转化、CPA、价值和数量。 |
| AP-A01 | 受众 | 国家、设备、客户类型、人口统计和受众选择符合资格且出于明确意图。 |
| AP-C01 | 创意 | 默认和自定义产品页与关键词、版位、受众及应用商店承诺相符。 |
| AP-C02 | 创意 | 产品页测试隔离创意或信息变更，且具备充分观察时间。 |
| AP-B01 | 预算 | 预算分配和投放节奏在资助已证实意图的同时保留发现空间。 |
| AP-B02 | 预算 | 仅在符合资格且有证据支持时，推荐基于目标的出价或自动化。 |
| AP-R01 | 报告 | 已披露货币、时区、延迟归因，以及 API 分页/报告完整性。 |
| AP-P01 | 政策 | 已检查应用、市场、年龄、隐私和产品资格要求。 |
| AP-E01 | 实验 | 测试定义假设、版位、主要指标、护栏和结果解读窗口。 |

使用 `pass`、`fail`、`unknown` 或 `not_applicable`。未知控制项会降低覆盖率。可选、测试版、高级、不可用、不可变或不符合资格的功能作为不评分的机会。

## 已登记官方证据

- `apple-ads-api-official`：[使用 Apple Ads API 功能](https://developer.apple.com/documentation/apple_ads/using-apple-search-ads-api-functionality)

官方来源发生变化时，以官方来源为准，而非本概述。缺乏支持的控制项保持为 `unknown`；供应商案例研究仍须标注来源并结合具体背景使用。
