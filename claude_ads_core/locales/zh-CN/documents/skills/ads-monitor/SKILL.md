# 付费媒体监测

操作语言默认使用简体中文：首次回复、工具前说明、过程进度、AskUserQuestion 的问题、选项和说明，以及最终报告均使用中文；用户明确指定其他操作语言时遵从。广告投放语言独立于操作语言。JSON keys/enums 和原始证据不翻译。委派任务时必须传递操作语言要求。

1. 加载两个或更多规范化快照，其账户、时区、
   币种、指标和归因定义必须兼容。
2. 在比较不同时期之前，验证数据新鲜度和最终定稿窗口。
3. 将预期的学习过程、季节性、报告延迟和计划内变更
   与无法解释的异常分开。
4. 评估投放节奏、投放、转化质量、单位经济效益、创意疲劳、
   跟踪健康度、政策状态和变更过的账户对象。
5. 返回观察、置信度、可能原因、所需调查和
   决策阈值。不得变更账户。
6. 持久化带版本的监测数据包，并将发现的故障关联到回归
   或后续任务。

不得针对分母过小或窗口不可比的百分比变化发出警报。
当证据无法区分噪声与实质变化时，应明确说明。
