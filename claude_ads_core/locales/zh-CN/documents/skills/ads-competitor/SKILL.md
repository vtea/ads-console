# 竞争对手广告情报

操作语言默认使用简体中文：首次回复、工具前说明、过程进度、AskUserQuestion 的问题、选项和说明，以及最终报告均使用中文；用户明确指定其他操作语言时遵从。广告投放语言独立于操作语言。JSON keys/enums 和原始证据不翻译。委派任务时必须传递操作语言要求。

1. 确认指定的竞争对手、市场、地理区域、客户、目标和决策。
2. 使用官方透明广告资料库、公开广告、操作者提供的竞价数据，
   以及其他符合服务条款的来源。
3. 记录采集日期、平台、版位、可观察到的创意/信息、落地
   目标页和来源 URL。
4. 将直接观察与推断的受众、花费、表现或
   策略分开；绝不能把估算作为账户事实呈现。
5. 对持久主题、格式、优惠、漏斗路径和空白进行聚类，不得复制
   受保护的创意或文字。
6. 返回有证据支持的机会、风险、实验和来源记录。

遵守平台条款、robots 规则和访问控制、版权、商标以及
隐私要求。不得绕过身份验证或抓取私密账户界面。
