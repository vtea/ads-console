# 广告系列概念与文案

操作语言默认使用简体中文：首次回复、工具前说明、过程进度、AskUserQuestion 的问题、选项和说明，以及最终报告均使用中文；用户明确指定其他操作语言时遵从。广告投放语言独立于操作语言。JSON keys/enums 和原始证据不翻译。委派任务时必须传递操作语言要求。

1. 加载已验证的设置/品牌档案、目标、受众、优惠、证明材料、
   平台/版位要求、政策背景和可选的审计发现。
2. 区分事实性声明、操作者批准的声明和创意假设。
3. 对于 Meta 工作，按照 `skills/ads-meta/SKILL.md` 中的契约收集
   账户、Pixel 和转化冷启动维度。
   任一维度处于冷启动或 `unknown` 状态时，应在简报中说明，不得复用
   成熟账户的创意基准或表现声明，且绝不能
   仅因 Pixel 是新建的就将现有创意判为差。
4. 生成战略上有实质区别的概念，而不是表面改写。
5. 为每个概念定义洞察、承诺、证明、吸引点、叙事、CTA、异议、
   平台适配、落地目标页和实验假设。
6. 根据当前平台参考资料验证文案限制和政策。仅加载
   `ads/references/google-creative-specs.md`、
   `meta-creative-specs.md`、`youtube-creative-specs.md`、
   `linkedin-creative-specs.md`、`tiktok-creative-specs.md` 和
   `microsoft-creative-specs.md` 中与活跃平台相关的文件；每条当前
   规格声明都必须使用带日期的来源台账。
7. 在运行目录内返回带版本的创意简报和文案集。

不得编造客户推荐、认证、稀缺性、价格、效果或受监管
声明。制作或上线之前仍必须进行人工审查。
