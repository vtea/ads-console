# 付费媒体优化

操作语言默认使用简体中文：首次回复、工具前说明、过程进度、AskUserQuestion 的问题、选项和说明，以及最终报告均使用中文；用户明确指定其他操作语言时遵从。广告投放语言独立于操作语言。JSON keys/enums 和原始证据不翻译。委派任务时必须传递操作语言要求。

默认使用 `--draft`。

1. 加载最新的规范化快照、既往决策、监测结果、
   实验状态、转化延迟、经济效益和平台能力清单。
2. 确定决策和因果证据；不得孤立地优化单一指标。
3. 比较不变更、实验和变更等选项，包括对学习、政策、
   跟踪、广告资源和机会成本的影响。
4. 生成排序后的建议，附带置信度和成功衡量标准。
5. 仅通过主变更门禁，将已批准的建议转化为
   变更计划。
6. 仅在精确操作已启用且远程状态仍符合草案前提条件时，
   才能执行、验证、审计并保留回滚方案。

绝不能将固定 CPA 倍数、预算比率、基准或新颖性声明作为
变更账户的唯一授权。

## 破坏性操作边界

必须拒绝永久删除广告系列、广告组、广告、受众、转化
或其他账户对象。永久删除不属于受支持的变更
契约，且不能通过确认就使其安全。提供可逆替代方案：
让对象保持暂停、在支持时归档、应用标签、导出备份，并
确定保留期限或后续审查日期。不得创建或执行删除计划。

搜索词操作需要搜索词报告、业务相关性证据
和过度屏蔽审查。缺少这些材料时，应请求缺失证据，不得
编造或举例说明具体的否定关键词。
